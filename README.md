## How I approach business analysis

- Start with the decision and the leader who needs to make it.
- Define financial and operating measures that connect to that decision.
- Validate source data, assumptions, and calculations.
- Show uncertainty and trade-offs in plain language.
- Translate findings into options, owners, and follow-up measures.
